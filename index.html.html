1. Área de trabalho

É a tela principal do Windows. Pode conter ícones, atalhos, a barra de tarefas e o Menu Iniciar.

A barra de tarefas permite acessar aplicativos e acompanhar programas/janelas em uso.

2. Janelas

  • Minimizar: tira a janela da tela, mas normalmente mantém o programa aberto.
  • Maximizar: faz a janela ocupar a área disponível.
  • Restaurar: retorna uma janela maximizada a um tamanho ajustável.
  • Fechar: encerra a janela/aplicativo correspondente.

3. Arquivos e pastas

Arquivo é uma unidade que armazena dados. Pasta é usada para organizar arquivos e pode conter outras pastas.

X = recortar → Ctrl+X
V = colar → Ctrl+V
Z = desfazer → Ctrl+Z
S = salvar → Ctrl+S
E = Explorador → Win+E

5. Explorador de Arquivos

É a ferramenta usada para navegar e administrar arquivos e pastas. É possível criar, copiar, mover, renomear, excluir, pesquisar e organizar itens.

6. Copiar × recortar

Copiar mantém o original e cria uma cópia quando o conteúdo é colado em outro local.

Recortar prepara o item para ser movido. Depois de colado em outro local, o item deixa o local anterior.

7. Lixeira

Arquivos excluídos normalmente são enviados para a Lixeira, de onde podem ser restaurados enquanto permanecerem nela. Esvaziar a Lixeira remove os itens que estão ali.

8. Atalho × arquivo original

Um atalho é uma referência para acessar rapidamente outro item. Ele não é necessariamente o arquivo original. Excluir um atalho não significa, por si só, excluir o item para o qual ele aponta.

9. Compactação

A compactação permite reunir e/ou reduzir o espaço ocupado por arquivos, dependendo do formato e do conteúdo. O .zip é um formato muito comum.

Compactar não é o mesmo que excluir. Um arquivo ZIP pode conter vários arquivos e pastas.

⭐ Antes de começar: se você lembrar de Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, Ctrl+S, Alt+Tab, Alt+F4, Win+E, Win+D e Win+L, já terá coberto uma parte importante dos atalhos básicos.
